# Fantasy Roster Review

Use this skill to retrieve and summarize Yahoo fantasy roster composition.

## Instructions

1. Use `get_team_roster` with an optional `team_key`.
2. Group players by position and team.
3. Highlight positional depth, thin spots, and concentration risk.
4. Keep recommendations tactical and tied to actual roster output.
